[en-US]

App Name
Debug Toolkit

Short description
Network diagnostics: Wi-Fi signal, speed tests, DNS lookups, TLS certs, HTTP.

Full description
Debug Toolkit is a straightforward set of network diagnostics for anyone who needs to understand what's happening on their connection — whether you're a developer, an IT professional, or just someone trying to figure out why the Wi-Fi feels slow.

Wi-Fi signal monitoring
See your live Wi-Fi signal strength in dBm, along with link speed and connection details, so you know exactly how strong your connection really is rather than guessing from a handful of bars.

Speed testing
Run download, upload, and latency tests to get a clear picture of your real-world network performance, powered by Cloudflare's speed test infrastructure.

TLS certificate inspection
Enter any hostname to view its certificate details — issuer, validity dates, and chain information — useful for verifying a site's security setup or troubleshooting certificate issues.

DNS lookups
Query any domain for its DNS records, with the option to choose which record type you need and which resolver to query. Fast, direct answers without needing a terminal.

HTTP header and response inspector
Enter any endpoint to see its response headers, status code, and timing — handy for debugging APIs, checking redirects, or understanding how a server responds.

Designed to feel native
Built entirely with Material Design 3, with full support for light and dark mode, so it fits naturally alongside the rest of your device.

Privacy by design
There's no account or login. Analytics and performance monitoring are strictly opt-in, and you can withdraw consent at any time from settings. Full details are available in the app's privacy policy.

Debug Toolkit doesn't try to do everything — it focuses on the handful of diagnostics people actually reach for, and does them cleanly, quickly, and without clutter.
